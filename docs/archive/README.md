bazıları onunla açıkça çelişir. Güncel durum için köke ve release kontrol merkezine bakın:

| Belge | Durum |
|---|---|

| `docs/FINAL_RELEASE_STATUS.md` | **Tek aktif release kontrol merkezi** |
